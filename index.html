muse-jmb

muse-jmb is a personal, non-commercial tool used only by its developer. It checks Japan Airlines Mileage Bank (JMB) award-seat availability for the developer's own trips and notifies the developer when seats become available. It only looks up availability; it never books or purchases anything.

To sign in to the developer's own JMB account, the tool reads the one-time verification code that JAL emails to the developer's Gmail inbox. It can also send notification emails to the developer's own address. It uses the Gmail API (scopes gmail.readonly and gmail.send) with the developer's own Google account only.

muse-jmb 是開發者自用、非商業的工具：查詢日本航空 JMB 里程兌換機位，有位子時通知開發者本人；只查詢，不訂位、不購買。為了登入開發者本人的 JMB 帳號，它會讀取 JAL 寄到開發者 Gmail 的一次性驗證碼，也會寄通知信給開發者本人。
